# Expaura Platform

Expaura Platform is a web-based solution for restaurants in Rwanda to improve customer experience, manage digital menus, collect feedback, and grow their online presence. The platform combines QR-based interactions, restaurant profiles, complaint tracking, analytics, and future-ready features such as reservations and online ordering.

## Overview

The platform helps restaurants:
- digitize menus and share them through QR codes
- collect customer feedback quickly and easily
- manage complaints and service issues
- monitor performance through analytics and review insights
- increase visibility through a public restaurant directory

## Key Features

- Restaurant registration and profile management
- Digital menu creation and updates
- QR code generation for each restaurant
- Customer review and complaint submission
- Analytics dashboard for ratings, trends, and complaints
- Public restaurant directory with search and discovery
- Subscription-based plans for different business needs

## Target Users

- Restaurant owners
- Restaurant managers
- Supervisors
- Customers
- Platform administrators

## Tech Stack

This project is built with:
- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the app.
